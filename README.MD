# Classroom

## About The App
Remote education LMS system for teaching and uploading homework

## Features
- Admin Panel
- Cart through a user session without authentication
- creating a ticket reservation
- downloading tickets to a pdf file with a barcode

## Technologies
- Python 3.13
- Fastapi
- Fastapi-Users
- SqlAlchemy
- Pydantic
- Alembic
- Pytest
- Celery(Near future) 
- PostgreSQL(Near future) 
- Docker(Near future) 
- Search by categories(Near future) 




## Installing the application via Github
```bash
git clone  https://github.com/olefinbrabus/classroom
cd Classroom
python -m venv venv
pip install -r requirements.txt
```

## Setting environment keys:
- Rename the File Sample.env to .env
- Enter the values you need in the keys
